# Airline Operations Analysis

Analyzed U.S. airline flight data using Excel and Power Query to identify patterns in flight delays, cancellations, and airline performance. The project focuses on turning operational data into clear metrics and insights that could support airline decision-making.

## Business Questions
Which airlines and routes experience the highest levels of flight delays?
How do departure delays vary across different time periods?
Which airlines have the highest proportion of delayed flights?
What operational patterns can be identified from flight performance data?

## Tools & Skills
Excel: PivotTables, XLOOKUP, KPI analysis, charts, conditional analysis
Power Query: Data import, cleaning, transformation, and preparation
Data Analysis: Delay rates, airline comparisons, operational trends
Data Visualization: KPI summaries, PivotCharts, and interactive analysis

## Data
The analysis uses U.S. flight operations data containing information such as:
Airline/carrier
Origin and destination airports
Scheduled and actual departure/arrival times
Departure and arrival delays
Delay indicators
Time-of-day categories
The raw dataset was cleaned and transformed in Power Query before being analyzed in Excel.

## Analysis
The project uses PivotTables and calculated metrics to compare airline performance and investigate operational trends. KPI summaries and visualizations were created to make the findings easier to interpret and communicate.

## Key Takeaways
The analysis highlights differences in delay patterns across airlines and time periods, demonstrating how operational flight data can be transformed into actionable performance insights using Excel.
